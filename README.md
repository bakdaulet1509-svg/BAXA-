# Қозғалыс — дене шынықтыру сабағын бақылау

Оқушы атын енгізіп сыныпқа тіркеледі, үйлесімді смарт сағатты Bluetooth арқылы қосады. Мұғалім сол сынып кодымен тақтаға кіріп, тіркелгендерді және жүрек соғысының соңғы көрсеткішін көреді.

## Іске қосу

Windows-та Node.js LTS орнатып, `Іске-қосу.ps1` файлын орындаңыз. Терминалда көрсетілген мекенжайды браузерде ашыңыз. Оқушы мен мұғалім бір сервердің мекенжайын және бір сынып кодын қолданады.

Толық орнату және HTTPS/Bluetooth талаптары: [ІСКЕ-ҚОСУ.md](ІСКЕ-ҚОСУ.md).

## Қолдау

Сағат Bluetooth стандартындағы Heart Rate Service (0x180D) жариялауы керек. Өндірушінің жеке қосымшасына ғана дерек беретін сағаттармен тікелей байланыс істемеуі мүмкін. Қазіргі нұсқа жүрек соғысын алады; қадам/орын деректеріне өндіруші API-і керек.

## Деректер

Оқушы тіркелімдері серверде `class-data.json` ішінде сақталады. Бұл файл Git репозиторийіне қосылмайды.
